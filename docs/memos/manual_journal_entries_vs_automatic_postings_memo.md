**Subject:** Assumptions and Methodology for Manual Journal Entries vs Automatic Postings

### Introduction
This memo serves to outline the assumptions and methodology employed in classifying manual journal entries versus automatic postings at Nubank. The analysis is grounded in the CSV transaction data derived from the urban-umbrella repository.

### Assumptions
1. **Definition Clarity:** Manual journal entries are defined as transactions that require human intervention for processing, while automatic postings are those that follow pre-established systems or rules without manual input.
2. **Data Reliability:** The CSV transaction data provided in the urban-umbrella repository is deemed accurate and representative of the actual operations conducted at Nubank.
3. **Transaction Types:** We considered various transaction types, including customer transactions, adjustments, and corrections, and categorized them based on their processing nature.
4. **Cut-off Criteria:** Transactions were analyzed over a defined period to ensure relevance and to capture the most current operational practices.

### Methodology
1. **Data Extraction:** Extracted transaction data from the urban-umbrella repository in CSV format for detailed analysis.
2. **Categorization:** Developed a categorization framework for identifying transactions as manual or automatic based on the definitions outlined.
3. **Data Analysis:** Utilized data analysis techniques to assess the volume of each transaction type, applying filters based on the established criteria for manual versus automatic postings.
4. **Verification and Validation:** Engaged in a verification process by cross-referencing heuristics from prior studies conducted within Nubank to ensure the accuracy of categorizations.
5. **Reporting:** Structured the findings into a comprehensive report that details the outcomes of the analysis, highlighting key insights regarding operational efficiencies and areas for improvement.

### Conclusion
This analysis provides valuable insights into the operational dynamics of Nubank's transaction handling. Understanding the distinction between manual journal entries and automatic postings is critical for improving efficiencies and ensuring compliance with SOX regulations.
